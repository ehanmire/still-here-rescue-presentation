# 아직 여기 — 10분 발표 자료

## 파일

- `still-here-10min-2026-10-09-design-v3.pdf`: 발표용 PDF. 오른쪽 화면 캡처를 누르면 해당 공개 데모 화면으로 이동합니다.
- `still-here-10min-2026-10-09-design-v3.pptx`: 수정 가능한 PowerPoint. 슬라이드 발표 노트에 발표 시나리오가 있습니다.
- `presentation-10min-scenario-2026-10-09.json`: 10장, 10분 발표 순서와 원고 초안.
